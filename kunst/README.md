# Wolfgang Grope Katalog

Die Ausstellung, die Besucher sehen, ist [biig.works/kunst](https://www.biig.works/kunst/).

Die Dateien dieser Ausstellung liegen im Projekt `friday-circle`. Dieser Branch liegt im Projekt `gogogo-social`. Deshalb ist die Live-Seite noch unverändert, bis die Dateien nach `friday-circle` kommen.

## So kommt es auf die Live-Seite

Am einfachsten: den Agenten noch einmal starten und dabei das Projekt `friday-circle` wählen. Dann kann er die Seite direkt ändern.

Wer es selbst über die Verwaltung machen will: `/kunst/admin/` öffnen, den GitHub-Zugangsschlüssel einfügen, Anmelden, Veröffentlichen. „Seiten-Code mit veröffentlichen“ bleibt an.
